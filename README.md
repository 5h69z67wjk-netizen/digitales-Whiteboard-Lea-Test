# Classroom Whiteboard

A small, browser-based whiteboard prototype for teachers and students. It is intentionally built with plain HTML, CSS, and JavaScript so it is easy to explore and change while learning vibe coding.

## Run it

Open `index.html` in a modern browser, or serve this folder with any static file server. No build step or dependencies are required.

## Try it out

- Draw with a mouse, touch screen, or stylus; choose pen, highlighter, or eraser.
- Pick an ink color and adjust stroke size.
- Undo and redo strokes, toggle the dotted grid, rename the lesson, and export a PNG.
- Use the role menu to switch between the teacher/student labels.
- Your sketch is saved in this browser's local storage.

## Prototype limitations

This is a local learning prototype, not a real-time classroom collaboration service. The teacher/student selector is a UI demonstration only, and the share button cannot synchronize boards across devices. Real multi-user collaboration would need a backend, accounts/room permissions, and a real-time transport such as WebSockets.
